# なんか。 — 肌管理アプリ

毎日の服薬・睡眠・肌・頭痛をひとつにまとめて記録し、朝の肌チェックから「今日1日の過ごし方」を提案する、スマホ向けの個人用Webアプリです。

**アプリを開く → https://miruhana.github.io/nanka/**

スマホのブラウザで開き、「ホーム画面に追加」するとアプリのように使えます。

## できること

| 画面 | 内容 |
|---|---|
| ホーム | 今日と明日の頭痛への注意度(通常 / 注意 / 警戒)と理由、服薬の達成数、昨夜の睡眠、今日の肌のひとこと |
| 服薬 | サプリ・薬の登録とチェック(飲むタイミング: 朝 / 昼 / 夜 / 就寝前 / 朝・夜 / 毎食後。1日に複数回のものは回ごとにチェック)、連続日数、体感メモ、7日間の服薬と肌の並び |
| 睡眠 | 就寝・起床時刻から睡眠時間を自動計算、質(5段階)・気分・習慣タグ、7日間のグラフとコメント |
| 肌 | 写真と自己評価チップからアドバイス、日付ごとの履歴 |
| 頭痛・天気 | 注意度と天気、頭痛の記録と振り返り、地域の追加・削除(最大5か所)、注意度の基準の変更、天気の手入力 |

初回はサンプルの記録が入った状態で開きます(「サンプル」の印つき)。ホームの「サンプルをすべて消す」で自分の記録だけになります。

## プライバシー

- 記録は **その端末のブラウザの中(localStorage)だけ** に保存されます。サーバーには送られず、ほかの人には見えません。誰がこのURLを開いても、見えるのはその人自身の記録だけです。
- 肌の写真は保存しません。アドバイスを作るときに一度だけ使います。
- 外部に送る情報は次だけです。
  - 天気: 登録した地名(国土地理院の住所検索)と、その位置(Open-Meteo)
  - アドバイス: 「Claudeとつなぐ」を設定したときだけ、写真と今日の記録を Anthropic の API へ
- 機種変更などに備えて、ホームの「データの管理」から記録を書き出し・読み込みできます。

## 天気の更新(毎朝)

1. **アプリを開いたとき**: 天気が今朝6時より前のものなら、自動で最新に取り直します。
2. **毎朝 5:45(日本時間)**: GitHub Actions(`.github/workflows/weather.yml`)が `regions.json` の地域の天気を取得し、`weather.json` を更新します。端末から天気サイトに直接つながらないときは、こちらを使います。
3. 取得できないときは前回の情報を「古い情報」と表示し、「頭痛・天気」画面から手入力で補えます。

天気は [Open-Meteo](https://open-meteo.com/)(気象庁などのモデルをもとにした予報)から、今日・明日の天気、最高/最低気温と前日との差、湿度、気圧とその変化を取得しています。

## Claude によるアドバイス(任意)

「肌」画面の「Claudeとつなぐ」に自分の Anthropic API キーを入れると、写真と記録から Claude(`claude-opus-5-5`)がアドバイスを作ります。キーはその端末のブラウザにだけ保存されます。利用料はキーの持ち主のアカウントにかかります。

キーを入れない場合は、自己評価と記録から端末の中だけで「かんたんアドバイス」を作ります(写真は使いません)。

## 医療に関する注意

このアプリは日々のセルフケアの参考を示すもので、診断や治療の代わりにはなりません。薬の量や飲み方の変更、飲み合わせの判断は、必ず医師・薬剤師に相談してください。突然の激しい頭痛や、ろれつが回らない・手足のまひなどがあるときは、すぐに救急や医療機関へ連絡してください。

## ファイル構成

```
index.html           画面とデザイン
app.js               アプリの処理(記録・注意度・アドバイス)
weather-core.js      天気の取得(アプリと GitHub Actions で共用)
weather.json         毎朝更新される天気(自動生成)
regions.json         毎朝の自動更新で調べる地域
scripts/update-weather.js
.github/workflows/weather.yml
sw.js, manifest.webmanifest, icon.svg   ホーム画面追加・オフライン用
```

ビルドは不要です。ローカルで試すときは、このフォルダで `npx serve` などの静的サーバーを起動して開いてください。
